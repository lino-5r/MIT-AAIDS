  • ■ Each image is a single Giemsa-stained red blood cell labeled Parasitized (infected with Plasmodium) or Uninfected. Pre-segmented by the NIH; the parasite appears as a dark ring-form inclusion.
  • ■ Three-way split: the NIH pre-defined a 2,600-image held-out test set (our evaluation lock-box, never seen during training).   • ■ Class balance is exact (50/50) across all three sets, so no sampling correction is needed. The class-weighting in CNN3 is a deliberate training choice, not a dataset correction.

Tuning Opportunities Model Tuning Roadmap
Lever 1: Triage thresholds
Set a low-confidence zone where borderline cells are routed to a microscopist. Adjusting the two thresholds trades referral volume against false-negative rate, without touching the model weights.
Auto: Uninfected Referred zone Auto: Parasitized
Lever 2: Class weight
CNN3 uses 2× cost for Parasitized. Increasing to 2.5× or 3× would push recall higher at the cost of more false positives. This requires retraining, but a fast one: no architecture change, no new data.
Lever 3: Input resolution
The jump from 64px to 32px improved recall. It is worth testing 48px as an intermediate to verify the relationship is monotonic. It is also worth testing 32px CNN3 with higher class weights to see if gains stack.
Longer-horizon improvements
A
Multi-site data
All training data comes from one institution with one staining protocol. Cross-site generalization is the largest unvalidated assumption.
B
Additional Plasmodium species
Trained on P. falciparum only. P. vivax, P. malariae, and P. ovale have distinct morphology not represented in the training set.
C
Whole-slide cell extraction
The model requires pre-segmented cells. Building an automated extraction layer closes the last manual step and enables a fully end-to-end pipeline.
D
Uncertainty quantification
Replace sigmoid probability with MC Dropout or a calibrated confidence estimate for a more principled referral boundary.

Evaluation Deploying CNN3-32px | Benefits, Risks, and Open Challenges
✓ Benefits
Highest recall at default threshold
No post-hoc tuning required. The training objective produces calibrated outputs that minimize missed infections without threshold manipulation.
Deployable without specialist hardware
  • ✓ ~2.1 MB on disk
  • ✓ No GPU required; runs on any modern laptop
  • ✓ $300-$500 per site; partner labs may already own suitable hardware
Dramatic workload reduction via triage
Triage mode auto-classifies ~98% of cells with high confidence. Microscopist review time drops from 8–25 person-hours/day to minutes.
Transparent failure mode
When the model is uncertain, it refers to a human. The system degrades gracefully and its errors are auditable from the sigmoid score distribution.
⚠ Risks
Single-source training data
  • ● All 27,558 images: one NIH study, one staining protocol
  • ● Cross-site generalization is the largest unvalidated assumption
  • ● Field performance may differ from test set performance
P. falciparum only
  • ● Not trained on P. vivax, P. malariae, or P. ovale
  • ● In multi-species regions, infections from other species will be missed
No interpretability layer
The model does not explain its decisions. Black-box outputs create accountability and trust gaps in high-stakes clinical settings, particularly for regulatory review.
Requires pre-segmented cells
The pipeline starts from individual cell images. Automated extraction from whole blood smear slides is not yet built, so a manual segmentation step remains at the upstream end.
ⓘ Challenges
Clinical trust and adoption
Lab directors and microscopists need evidence that the model performs reliably before they will defer to it. Building that evidence requires a parallel-run pilot period.
Regulatory and ethics clearance
Clinical AI in many target countries requires IRB/ethics review and local health authority approval before deployment. Timelines vary widely by jurisdiction.
Workflow and LIS integration
The model must connect to existing lab information systems, microscope cameras, and reporting workflows. Each partner lab will have a different integration surface.
Ongoing drift monitoring
Staining batches, microscope calibration, and sample preparation can shift over time. Production deployment requires a monitoring loop so distribution shift is detected before it affects clinical decisions.

Phase 2 gate

Phase 3 gate
End-to-end pipeline processes a full slide within 5 minutes at ≥99% recall vs. manual baseline
Phase 4 gate
Recall ≥95% maintained at each new site without retraining; regulators notified for approval pathway
Signals that trigger model retraining
📈 Recall degradation
Field recall falls below 97% at any monitored site. Collect and label new slides; retrain with site-specific augmentation.
🔍 Distribution shift
Referral rate drifts above 5% (sigmoid score distribution is shifting). Recalibrate triage thresholds first; retrain if drift persists.
🏭 New site conditions
New species or staining protocol introduced at a partner site. Targeted fine-tuning on a representative local sample before live deployment.
