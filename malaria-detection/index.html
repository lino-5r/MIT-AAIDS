About this project

This is the capstone project for the MIT Applied AI and Data Science Program (2026). The goal was to build and evaluate a deep learning pipeline for binary malaria cell classification — Parasitized vs. Uninfected — using the publicly available NIH cell image dataset of 27,558 Giemsa-stained blood smear images.

Six model variants were evaluated, including baseline CNNs, augmented and class-weighted variants, and a MobileNetV2 transfer learning experiment. The recommended model, CNN3 trained at 32×32px with class weighting, achieved 99.69% recall (4 false negatives in 1,300 test images) with an AUC of 0.999. All figures and metrics are generated programmatically from the source notebook.

Fictitious NGO branding: Claros — focused on improved pathology outcomes in developing countries.
